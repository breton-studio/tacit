# Tacit M1+M2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A working menu bar app: webcam → hand landmarks → clutch-gated gesture recognition → user-configured actions, with the specimen-book Library UI, covering spec milestones M1 (skeleton & clutch) and M2 (workhorses).

**Architecture:** Pure SwiftPM, two targets. `TacitCore` is a dependency-free library holding everything fixture-testable (models, geometry, classifiers, arbitration, catalog, mapping store, action dispatch); `Tacit` is the executable app (AVFoundation capture, Vision detection, SwiftUI menu bar/HUD/Library) bundled into `Tacit.app` by `scripts/make-app.sh`. No `.xcodeproj` — everything builds and tests from the CLI.

**Tech Stack:** Swift 6 (toolchain 6.3.3), SwiftUI + AppKit, Vision (`DetectHumanHandPoseRequest`), AVFoundation, ServiceManagement (`SMAppService`). Zero third-party dependencies.

**Spec:** `docs/superpowers/specs/2026-08-23-tacit-design.md` — read it before starting any task. UI tasks MUST also re-read spec §4 (binding visual/motion rules) and §5 before writing code.

## Global Constraints

- Deployment target: **macOS 15**. Machine runs macOS 26.6; Xcode 26.6 lives at `/Applications/Xcode.app` but is NOT the active developer dir — every build/test command goes through the wrapper scripts, which set `DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer`. Never run bare `xcodebuild`; never run `sudo`.
- Test command: `./scripts/test.sh` (wraps `swift test`). Build app: `./scripts/make-app.sh` → `build/Tacit.app`.
- **No third-party dependencies.** No new SPM packages without user approval.
- `TacitCore` must never import AVFoundation, Vision, AppKit, or SwiftUI. (CoreGraphics types like `CGEventFlags` raw values are wrapped in own types instead.)
- All UI motion uses tokens from `Sources/Tacit/TacitMotion.swift` — magic-number animations are a review-rejection.
- Spec §4 quality floor is acceptance criteria for every UI task: Reduce Motion fallback on every animation, contrast ≥ 4.5:1, hit targets ≥ 44×44 pt, keyboard focus visible, interruptible value-driven springs only.
- One accent color (`Color("Accent")` asset, fallback `.orange` until user picks) used ONLY for the armed/active state. All gesture imagery via `ConstellationRenderer` — never SF Symbol hands.
- Commit after every task (message style: `feat: …`, `test: …`, `chore: …`). Repo: `~/Developer/tacit`, branch `main`, remote `origin` (github.com/breton-studio/tacit).
- Vision landmark coordinates are normalized with **origin at lower-left** (y up). All of TacitCore assumes this convention; the detector layer converts and un-mirrors before anything else sees a frame.
- Naming/copy: plain verbs, action keeps its name through a flow (spec principle 9). The two reserved gestures are `looseFist` (clutch) and `openPalm` (disarm) — never user-bindable.

### Task 5: ArbitrationEngine — clutch FSM, debounce, hysteresis, cooldown

- Consumes: Task 2 types.
- Produces:

```swift
public struct ArbitrationTuning: Sendable {
    public var clutchHold: TimeInterval = 0.4
    public var commandWindow: TimeInterval = 4.0
    public var debounceFrames: Int = 3
    public var cooldown: TimeInterval = 0.8
    public var enterConfidence: Double = 0.6
    public var stayConfidence: Double = 0.45
    public init()
}
public enum ArbitrationState: Equatable, Sendable {
    case disarmed
    case arming(progress: Double)        // 0..1 of clutchHold
    case armed(windowEndsAt: TimeInterval)
}
public final class ArbitrationEngine {
    public init(tuning: ArbitrationTuning = ArbitrationTuning())
    public private(set) var state: ArbitrationState
    /// Feed exactly one sample per inference frame (nil = nothing classified).
    /// Returns a fired event, or nil. Mutates state.
    public func ingest(_ candidate: GestureCandidate?, at now: TimeInterval) -> GestureEvent?
    public func reset()
}
```

Behavioral contract (each bullet = at least one test):
1. Disarmed + sustained `looseFist` ≥ `clutchHold` → state becomes `.armed`; the clutch itself NEVER returns a GestureEvent.
2. Fist released mid-arming → back to `.disarmed`.
3. Armed + `openPalm` (debounced) → immediate `.disarmed`, no event.
4. Armed + non-reserved candidate with confidence ≥ enterConfidence for `debounceFrames` consecutive ingests → returns event once; window end extended to `now + commandWindow`.
5. Frames 1–2 above enterConfidence + frame 3 between stayConfidence and enterConfidence still count (hysteresis); a frame below stayConfidence resets the count.
6. After firing, same gesture within `cooldown` → no event even if debounced again.
7. No candidates until `windowEndsAt` → auto `.disarmed`.
8. While disarmed, non-clutch candidates NEVER fire (Midas-touch defense).
9. `reset()` → `.disarmed`, counters cleared.

- [ ] **Step 1: Write the nine failing tests.** Drive with a helper `feed(_ engine:, gesture: GestureID?, conf: Double, from: TimeInterval, frames: Int, dt: 1.0/15.0) -> [GestureEvent]`. Example for #4:

import TacitCore

enum LiveActionEnvironment {
    static func make() -> ActionEnvironment {
        ActionEnvironment(
            postKeystroke: { chord in
                var flags = CGEventFlags()
                if chord.modifiers.contains(.command) { flags.insert(.maskCommand) }
                if chord.modifiers.contains(.shift)   { flags.insert(.maskShift) }
                if chord.modifiers.contains(.option)  { flags.insert(.maskAlternate) }
                if chord.modifiers.contains(.control) { flags.insert(.maskControl) }
                guard let down = CGEvent(keyboardEventSource: nil, virtualKey: chord.keyCode, keyDown: true),
                      let up = CGEvent(keyboardEventSource: nil, virtualKey: chord.keyCode, keyDown: false)
                else { return false }
                down.flags = flags; up.flags = flags
                down.post(tap: .cghidEventTap); up.post(tap: .cghidEventTap)
                return true
            },
            launchApp: { bundleID in
                guard let url = NSWorkspace.shared.urlForApplication(withBundleIdentifier: bundleID) else { return false }
                NSWorkspace.shared.openApplication(at: url, configuration: .init(), completionHandler: nil)
                return true
            },
            openURL: { string in
                guard let url = URL(string: string) else { return false }
                return NSWorkspace.shared.open(url)
            },
            runShortcut: { name in
                let p = Process()
                p.executableURL = URL(fileURLWithPath: "/usr/bin/shortcuts")
                p.arguments = ["run", name]
                do { try p.run(); p.waitUntilExit(); return p.terminationStatus == 0 } catch { return false }
            },
            isAccessibilityTrusted: { AXIsProcessTrusted() }
        )
    }
