**Goal:** Ship the dynamic gesture layer (hand swipes, fist→open, wrist-rotate ticks, two-finger-scroll ticks, pinch-drag preview), low-light handling, and the Library Settings tab (camera picker, sensitivity trim) — spec milestone M3 plus the two items descoped from M2 by ruling.

**Architecture:** Same two-target SwiftPM layout as M1/M2. All recognition additions are pure TacitCore (fixture/synthetic-TDD); app-target work is Settings UI, camera switching, and luma sampling. The M1/M2 conventions are LAW here — read the Conventions block below.

**Spec:** `docs/superpowers/specs/2026-08-23-tacit-design.md` (§3.3 temporal state machines, §4 binding visual rules, §5 Settings tab, §6 low-light row, §9 M3 scope). Ergonomics source: `docs/research/LowFatigue-Economic-Hand-Gestures.md` (gestures 10–17 rows; wrist-rotate partial-arc caveat).

## Global Constraints (M1/M2 conventions, binding)

- Build/test ONLY via `./scripts/test.sh` and `./scripts/make-app.sh` (they set `DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer`). Never bare `xcodebuild`, never `sudo`.
- TacitCore imports Foundation only; ZERO `Date()`/clock reads in recognition paths (all time flows from `frame.timestamp` / the `now:` parameter — fixture replay depends on it).
- Swift Testing (`import Testing`, `@Test`/`#expect`), TDD red→green per step.
- All UI animation via `TacitMotion` tokens + `respecting(reduceMotion,…)`; accent (`TacitColors.accent`) ONLY for armed/active semantics; gesture imagery only via `ConstellationRenderer`; plain-verb copy; ≥44 pt targets (`TacitButtonStyle`/`TacitToggleStyle` in `SharedControls.swift`).
- Detectors are value types with `mutating func ingest(_ frame: LandmarkFrame) -> GestureCandidate?` (see `PinchTapDetector`/`ThumbSwipeDetector` for the house pattern: one-frame jitter tolerance, reset discipline, confidence = `HandGeometry.meanConfidence`).
- Preview detector instances are ALWAYS separate from production instances (see `PipelineCore` in `Sources/Tacit/TacitEngine.swift`); preview must never perturb the arbitration path; preview momentary candidates latch 0.6 s (existing `previewLatch`).
- Reserved gestures (`looseFist`, `openPalm`) stay unbindable and never dispatch.
- Commit + push to main after every task. Repo `~/Developer/tacit`, remote `breton-studio/tacit`.

## Rulings encoded in this plan (spec refinements)

1. **GestureID split (precedent: thumbSwipe pair):** `wristRotate` → `wristRotateCW` + `wristRotateCCW`; `twoFingerScroll` → `twoFingerScrollUp` + `twoFingerScrollDown`. GestureID goes 21 → 23 cases; catalog 23 entries; tier partition becomes 10/10/3.
2. **`pinchDrag` ships recognition + preview only** — stays unbindable in v1 (its catalog editorial already says so; true 2D continuous control is v2).
3. **Repeat-tick semantics:** rotate/scroll gestures emit a tick per motion increment while engaged. `ArbitrationEngine` gains a repeatable-gesture set with a short repeat cooldown (0.2 s) used instead of the 0.8 s cooldown, ticks flow through `ingestPreDebounced`, and each tick extends the command window.
4. **Mappings schema v1 → v2:** version bump with migration (old `wristRotate`/`twoFingerScroll` keys dropped; everything else carried; corrupt/unknown recovery unchanged).
5. **Swipes must stay silent through the conversation negative stream** — the deliberate-motion thresholds are tuned against it honestly (no test softening; production tuning is the escalation path, exactly as Task 13's precedent).
6. **Low-light policy:** luma sampled in the app layer; the POLICY (threshold hysteresis + confidence raise) is pure core and TDD'd.

### Task 2: HandSwipeDetector (swipes L/R/U/D + fistToOpen)

**Files:** Create `Sources/TacitCore/HandSwipeDetector.swift`, `Tests/TacitCoreTests/HandSwipeDetectorTests.swift`.

**Interfaces:**
```swift
public struct HandSwipeDetector: Sendable {
    public init(minTravel: Double = 1.2,        // palm-size units of palm-center travel
                maxDuration: TimeInterval = 0.45,
                minMeanSpeed: Double = 4.0,      // palm-units/second — deliberateness gate
                dominanceRatio: Double = 2.0)    // major axis must exceed minor × this
    public mutating func ingest(_ frame: LandmarkFrame) -> GestureCandidate?  // .swipeLeft/.swipeRight/.swipeUp/.swipeDown
}
public struct FistToOpenDetector: Sendable {
    public init(maxTransition: TimeInterval = 0.5)
    public mutating func ingest(_ frame: LandmarkFrame) -> GestureCandidate?  // .fistToOpen
}
```
Swipe algorithm: track palm center (mean of wrist+MCPs) per frame; a swipe = net displacement ≥ minTravel within ≤ maxDuration AND mean speed ≥ minMeanSpeed AND axis dominance (|Δmajor| ≥ dominanceRatio×|Δminor|); hand must be open-ish (≥3 fingers extended) throughout; emit once on threshold-cross, then require a settle (2 consecutive low-motion frames) before re-arming. One-frame jitter tolerance per house pattern. Left/right are in the UN-MIRRORED user frame (x already flipped upstream — document). FistToOpen: `.looseFist`-classified frame(s) followed by `.openPalm`-classified frame within maxTransition (use `StaticPoseClassifier` internally with default tuning) — emit on the open frame; reset discipline per house pattern.

- [ ] **Step 1: Failing tests** — synthetic sequences built from SyntheticHand by translating all joints: right-swipe over 0.3 s at sufficient speed → `.swipeRight` exactly once; too-slow same-path → nil; diagonal (no dominance) → nil; fisted-hand translation → nil; up-swipe → `.swipeUp`; settle-then-second-swipe → fires again; fist frames → open frames within 0.4 s → `.fistToOpen`; fist → open after 0.8 s → nil.
- [ ] **Step 2: red → implement → green. Commit** `feat: hand swipe and fist-to-open detectors`, push.

### Task 3: WristRotateDetector + TwoFingerScrollDetector (repeat ticks) + PinchDragDetector

**Files:** Create `Sources/TacitCore/RotateScrollDetectors.swift`, `PinchDragDetector.swift`, tests for each.

**Interfaces:**
```swift
public struct WristRotateDetector: Sendable {
    public init(tickArcDegrees: Double = 20, maxArcDegrees: Double = 70)
    public mutating func ingest(_ frame: LandmarkFrame) -> GestureCandidate?  // .wristRotateCW / .wristRotateCCW per tick
}
public struct TwoFingerScrollDetector: Sendable {
    public init(tickTravel: Double = 0.35)     // palm-units vertical per tick
    public mutating func ingest(_ frame: LandmarkFrame) -> GestureCandidate?  // .twoFingerScrollUp / .twoFingerScrollDown per tick
}
public struct PinchDragDetector: Sendable {
    public init(tuning: ClassifierTuning = ClassifierTuning(), minHold: TimeInterval = 0.25)
    /// Emits .pinchDrag ONCE when a held pinch (past minHold, disambiguating from taps) begins
    /// translating; preview-only consumer in v1.
    public mutating func ingest(_ frame: LandmarkFrame) -> GestureCandidate?
}
```
Rotate: engaged while hand is fisted (4 fingers curled); measure the wrist→middleMCP vector angle; accumulate signed delta; every `tickArcDegrees` emit a tick (CW = clockwise in the user's view — document sign convention against the un-mirrored frame); clamp per-engagement total at `maxArcDegrees` (Rempel partial-arc caveat — stop ticking, require return toward neutral). Scroll: engaged while exactly index+middle extended (victory-like but tips together allowed — do NOT require the victory spread); accumulate vertical tip travel; tick per `tickTravel`. Both: disengage resets accumulators; one-frame jitter tolerance.

- [ ] **Step 1: Failing tests per detector** — rotate: 45° CW sweep at defaults → exactly 2 CW ticks; CCW sweep → CCW ticks; 90° sweep → ticks stop at the 70° clamp (3 ticks max at 20°/tick); open-hand rotation → nil. Scroll: two-finger down-travel 0.8 units → 2 down ticks; same travel with all fingers extended → nil. PinchDrag: pinch held 0.3 s then translated → one `.pinchDrag`; quick tap (release <0.25 s) → nil (tap detector's territory).
- [ ] **Step 2: red → implement → green. Commit** `feat: rotate, scroll, and pinch-drag detectors`, push.

public struct LowLightPolicy: Sendable {
    public init(lumaThreshold: Double = 0.18, enterAfter: TimeInterval = 5, exitAfter: TimeInterval = 3)

### Task 9: Hold-gesture semantics + holdKeystroke action (user requirement, added mid-M3)

**Files:** Create `Sources/TacitCore/HoldTracker.swift` + tests; modify `ArbitrationEngine.swift` (hold-aware window), `TacitAction.swift` (+`.holdKeystroke(KeyChord)`), `ActionDispatcher.swift` + `ActionEnvironment` (+`postKeyDown`/`postKeyUp` closures), `Sources/Tacit/LiveActionEnvironment.swift` (CGEvent down-only/up-only posting incl. Fn keyCode 63 via `.maskSecondaryFn` when keyCode==63), `TacitEngine.swift` (begin/end dispatch), HUD (`show` persists while holding: "Dictating…"-style copy = "<Gesture> → holding <summary>"; dismiss on end).

**Interfaces:**
```swift
public enum HoldPhase: Equatable, Sendable { case began, ended }
public struct GestureHoldEvent: Equatable, Sendable { public var gesture: GestureID; public var phase: HoldPhase; public var timestamp: TimeInterval }
public struct HoldTracker: Sendable {
    public init(holdableGestures: Set<GestureID>, releaseAfterMissingFrames: Int = 2)
    /// Feed the fired event (if any) + the raw static candidate each frame; emits began after a
    /// holdable gesture FIRES and its pose persists, ended when the pose stops classifying for
    /// releaseAfterMissingFrames consecutive frames (or on reset()).
    public mutating func ingest(fired: GestureEvent?, candidate: GestureCandidate?, at now: TimeInterval) -> GestureHoldEvent?
    public mutating func reset() -> GestureHoldEvent?   // emits ended if a hold was active
}
```
Rules: only static poses are holdable (v1 set: `[.indexPoint, .thumbsUp, .victory]`); while a hold is active the engine keeps the arbitration window alive (call a new `ArbitrationEngine.extendWindow(at:)` public method each held frame); a hold's `ended` must ALWAYS eventually fire (missing frames, disarm, capture pause, reset — engine calls tracker.reset() on those paths and dispatches the keyUp; a stuck-down Fn key is the failure mode to make impossible). `.holdKeystroke` requiresAccessibility=true; summary "Hold ⌥Space" style ("Hold Fn" for 63). Dispatcher: `.holdKeystroke` is NOT dispatched via the normal fire path — the engine routes began→postKeyDown, ended→postKeyUp; a fire of a holdKeystroke-bound gesture with no hold support (momentary gestures) falls back to a normal down+up press (documented).
- [ ] TDD HoldTracker (began after fire+persist; ended on 2 missing; reset ends; non-holdable fires ignored). TDD dispatcher env additions (spies). Wire engine begin/end incl. all ended-paths; HUD hold display. Commit `feat: hold gestures with key-down/up semantics`, push.
