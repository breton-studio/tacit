# Tacit M4 Implementation Plan — Cartoon Hand Previews + Try-It Sessions (with hb-motion)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Every gesture gets a looping 3D cartoon-glove animation (rendered by the new standalone `hb-motion` pipeline) shown in the Library, plus an interactive Try-It session: click a gesture, perform it, get a clear registered/not-registered verdict.

**Architecture:** Two repos. `~/Developer/hb-motion` (separate git repo, github.com/breton-studio/hb-motion, private) is a project-agnostic animation service: Blender 5.2 headless + Auto-Rig Pro (installed & verified via `scripts/bootstrap.py` — ALREADY WORKING) animate a scripted five-finger cartoon glove; choreography JSONs → keyframes → transparent PNG frames → HEVC-with-alpha `.mov` via a native Swift AVAssetWriter tool (no ffmpeg). `~/Developer/tacit` consumes the exported assets: bundled into the app, played with AVPlayerLooper in the Library, with graceful constellation fallback.

**Tech Stack:** Blender 5.2 LTS bpy (Python), Auto-Rig Pro (licensed), Swift/AVFoundation encoder tool, SwiftUI/AVKit in Tacit.

**Specs:** Tacit spec `docs/superpowers/specs/2026-08-23-tacit-design.md` (§4 binding visual rules still govern all Tacit UI; the cartoon hand is a NEW sanctioned identity element for gesture imagery — it complements, never replaces, the constellation in glyph/HUD). User decisions: cartoon renders only (no landmark-driven constellation animation); ARP stack; try-it with verdict; hb-motion as a reusable service.

## Global Constraints

- Tacit conventions unchanged (scripts/test.sh, scripts/make-app.sh, TacitMotion tokens, plain verbs, 44pt, accent discipline, Swift Testing, commit+push per task).
- hb-motion conventions: Blender CLI = `/Applications/Blender.app/Contents/MacOS/Blender --background --python <script> -- <args>`; every scene artifact REBUILDABLE FROM CODE (the .blend is a build product; scripts are the source of truth); deterministic renders (fixed seeds, fixed samples); `.secrets/` never committed; commit+push per task (separate repo, same identity).
- The glove is FIVE-fingered (Tacit distinguishes ring/pinky taps) — Mickey-glove spirit, not literal four-finger anatomy. White glove, simple dark wrist cuff, soft studio lighting, transparent background.
- The armature's 21 deform bones are named EXACTLY Tacit's HandJoint rawValues (wrist, thumbCMC, thumbMP, thumbIP, thumbTip, indexMCP, indexPIP, indexDIP, indexTip, middleMCP…, ringMCP…, littleMCP…littleTip) — choreography vocabulary matches the app's model. (ARP may generate its own control rig on top; the deform layer keeps these names.)
- Asset contract (hb-motion → any consumer): `dist/<gestureID>.mov` (HEVC with alpha, 640×640, 30fps, loop-friendly first≈last frame) + `dist/<gestureID>.png` (poster, alpha). gestureIDs = Tacit's 23 GestureID rawValues.
- Tacit UI: video previews appear ONLY in the Library (grid poster + hover-play, detail hero loop) and Try-It; menu bar glyph and HUD keep the constellation identity.

## Rulings

1. hb-motion is its own repo/service (user-directed) — Tacit stores only the exported assets under `Sources/Tacit/Resources/previews/` (committed: they're build inputs for the app bundle; ~23 × ≤400KB ≈ manageable).
2. `twoHandFrame` renders ONE glove performing the half-frame (an "L"); the editorial explains both hands. Rendering two gloves is a v2 nicety.
3. Try-It sessions bypass the clutch via the EXISTING preview pipeline (previewCandidate) — no arbitration changes.
4. Grid cards show the poster PNG, playing on hover (frequency gate: browsing is frequent; 23 simultaneous looping videos is noise + energy). Detail hero loops always. Reduce Motion: poster only, video plays on explicit click.

### Task 1 (hb-motion): Cartoon glove hand — mesh, armature, skinning, look

**Files:** Create `scripts/build_hand.py`; output `rig/hand.blend` (committed as build product with a REBUILD note).

**Interfaces:** Produces the rig every later task poses: armature `HandRig` with the 21 named deform bones (Global Constraints); mesh `Glove` parented with weights; material `GloveWhite` (subsurface-ish soft white) + `Cuff`; a `CAMERA_MAIN` (front-facing, slight ¾ angle) and three-point soft lighting; world transparent.

- [ ] **Step 1:** Script the mesh: box-modeling via bpy — palm block, five finger extrusions (four fingers from the palm top edge loops + opposed thumb), subdivision surface modifier (2 levels) + smooth shading for the balloon-glove look; slightly oversized rounded fingertips (cartoon read); a flared cuff cylinder at the wrist. Keep proportions from a hand-tuned constants block (finger lengths/radii) so taste iterations are one-dial edits.
- [ ] **Step 2:** Script the armature: 21 bones in the exact named topology (wrist root; chains per finger), positioned inside the mesh from the same constants; parent mesh → armature with automatic weights; verify each fingertip bone moves only its finger (scripted check: rotate indexPIP 60°, assert middle fingertip vertices unmoved beyond epsilon — bpy vertex sampling).
- [ ] **Step 3:** Look: materials, lights, camera, film transparent, EEVEE Next; render a test still `out/hand-test.png`; scripted assertions: file exists, has alpha variance (not fully opaque/empty), non-trivial white-pixel share. ARP note: if automatic weights produce artifacts, use ARP's skinning on the same deform bones — implementer's call, document.
- [ ] **Step 4:** `git commit -m "feat: scripted cartoon glove hand rig"` + push (hb-motion repo).

### Task 2 (hb-motion): Pose model + choreography engine

**Files:** Create `scripts/pose.py`, `scripts/choreograph.py`, `choreography/poses.json`, one sample `choreography/gestures/thumbIndexTap.json`.

**Interfaces:**
- Pose parameter model (poses.json entries): `{ "name": ..., "fingers": {"index": {"curl": 0..1, "spread": -1..1}, ...}, "thumb": {"curl": 0..1, "oppose": 0..1}, "wrist": {"pitch": deg, "yaw": deg, "roll": deg}, "location": [x,y,z] }`. pose.py maps curl → distributed MCP/PIP/DIP rotations (e.g. curl×[55°,70°,40°]), spread → MCP z-rotation, thumb oppose → CMC rotation; applies to the named bones.
- Choreography schema (gestures/<id>.json): `{ "fps": 30, "frames": N, "loop": true, "keys": [ {"frame": 0, "pose": "openRelaxed"}, {"frame": 12, "pose": "pinchIndexClosed", "ease": "EASE_IN_OUT"} ... ] }` — poses by name from poses.json, optional inline overrides, Bezier interpolation defaults, ease per key.
- choreograph.py: load rig/hand.blend, apply choreography, keyframe all touched bones, set scene frame range; callable from render.py.
- [ ] **Step 1:** Implement pose.py + a scripted self-test (blender --background): apply "fist" pose, assert indexTip world-position dropped below its rest position; apply "openRelaxed", assert restored.
- [ ] **Step 2:** Implement choreograph.py + self-test: load thumbIndexTap.json, assert keyframe count > 0 on thumb bones and scene frame_end == frames-1; first and last key pose names equal when loop==true (loop-friendliness lint).
- [ ] **Step 3:** poses.json initial vocabulary: openRelaxed, openPalm (spread), looseFist, indexPoint, victory, thumbsUp, pinchIndexClosed/Open, pinchMiddleClosed, pinchRingClosed, twoFingerScrollPose, fistForRotate — enough for Task 3. Commit + push.

### Task 3 (hb-motion): All 23 gesture choreographies

**Files:** Create `choreography/gestures/<id>.json` for all 23 Tacit GestureIDs.

Loop design per family (1.5–2.5 s each, loop-friendly): taps = rest→approach→touch (2 frames)→release→rest; thumb swipes = fist + thumb travel fwd/back; hand swipes = openRelaxed translating (screen-space ±0.25 units) with slight lean, snap-back through a fade-friendly rest; fistToOpen = fist(hold)→open(bloom)→rest; rotate CW/CCW = fist wrist-roll ±45° and back; scrolls = two-finger pose translating vertically; pinchDrag = pinch close→translate→release; palmPush = palm toward camera (scale up ~8%)→back; wave = open hand wrist yaw oscillation ×2; twoHandFrame = "L" pose hold with a small settle (Ruling 2); looseFist = fist forming + hold (the clutch — editorial star); openPalm = palm presenting + hold.
- [ ] **Step 1:** Author all 23 JSONs; extend poses.json as needed. Scripted lint (extend choreograph self-test): every Tacit GestureID rawValue (hardcode the 23-item list with a comment to sync with Tacit) has a file, parses, loops cleanly, frames within 45–75.
- [ ] **Step 2:** Commit + push.

### Task 5 (hb-motion): HEVC-alpha encoder tool
